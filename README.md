# LEGENDS XI — Football Time Machine
**Created by Dr HOSSAM Mo**

تطبيق Android: موسوعة تاريخية لكرة القدم + ألعاب معرفة.

## الحصول على ملف APK (بدون تثبيت أي برامج)
1. أنشئ مستودعًا جديدًا على GitHub (يمكن أن يكون خاصًا Private).
2. ارفع كل محتويات هذا المجلد إليه (زر **Add file → Upload files**، واسحب الملفات والمجلدات).
3. افتح تبويب **Actions** — سيبدأ البناء تلقائيًا (حوالي 8–12 دقيقة).
4. عند انتهائه ستجد ملف **LEGENDS-XI.apk** في:
   - صفحة **Releases** في المستودع، أو
   - صفحة تشغيل الـ Action تحت **Artifacts**.
5. حمّل الملف على هاتفك وافتحه، واسمح بالتثبيت من مصادر غير معروفة عند الطلب.

كل رفع جديد على الفرع `main` يبني نسخة جديدة تُثبَّت فوق السابقة مباشرة (توقيع ثابت للمشروع).

### للنشر على Google Play لاحقًا (اختياري)
أنشئ مفتاح توقيع خاص بك، ثم أضف في **Settings → Secrets → Actions**:
`LXI_KEYSTORE_BASE64` (الملف بصيغة base64)، `LXI_KEYSTORE_PASSWORD`، `LXI_KEY_ALIAS`، `LXI_KEY_PASSWORD`.
عندها سيبني الـ Action نسخة Release موقّعة بمفتاحك تلقائيًا.

## هيكل المشروع
| المسار | المحتوى |
|---|---|
| `data-src/` | قاعدة البيانات كنصوص قابلة للتعديل: `teams.txt`، `players*.txt`، `squads.txt` |
| `data-src/build.py` | يتحقق من البيانات ويولّد `www/js/data.js` (يرفض أي خطأ: لاعب ناقص، كود نادي مجهول، تشكيلة ليست 11…) |
| `www/` | التطبيق نفسه (HTML/CSS/JS) |
| `android/` | مشروع Android الأصلي (Capacitor) |
| `.github/workflows/build-apk.yml` | البناء التلقائي على GitHub |

## إضافة بيانات
- **لاعب**: سطر في أي ملف `players*.txt`:
  `id|English|عربي|N-XXX|POS|YYYY-MM-DD|tier|NTfrom-NTto|CLUB 1996-2001; CLUB2 2001-2005|WC2002 CL2005|aliases`
  السنوات = سنة بداية الموسم الأول – سنة نهاية الموسم الأخير.
- **تشكيلة**: كتلة جديدة في `squads.txt` (الصيغة موضحة أعلى الملف). الرقم غير المعروف يُكتب `-` ليظهر "غير موثق".
- ثم شغّل: `python3 data-src/build.py`

## أجيال الأندية (203 تشكيلة جديدة، آخر 30 عامًا)
- **131 تشكيلة موثقة** من [StatsBomb Open Data](https://github.com/statsbomb/open-data): لكل فريق وموسم تُختار المباراة الحقيقية الأقرب إلى التشكيلة الأساسية المعتادة (الدوريات الخمس الكبرى 2015/16، الدوري الإسباني 2004–2021، الإنجليزي 2003/04، الفرنسي 2021–2023، الألماني 2023/24، ونهائيات دوري الأبطال).
  - `sb/select.txt`: الفرق والمواسم المختارة + «إلى أين وصل هذا الجيل». `sb_extract.py` ← `sb_resolve.py` ← `sb_apply.py` تولّد `players_sb.txt` و`squads_sb.txt`. الأسماء العربية في `sb/names.txt`.
- **72 تشكيلة** (نهائيات أوروبية وأجيال تاريخية مثل ليدز 2001 وبارما 1999 ولاتسيو 2000 وروما 2001 وأياكس 2019) في `gen/gens.txt` بأسماء اللاعبين، و`gen_apply.py` يحوّلها إلى `squads_gen.txt`. نهائي 1999 موثّق من سجل المباراة، والباقي "معرفة تاريخية".
- في ملفات التشكيلات: السطر الذي يبدأ بـ `>` هو قصة الجيل وإلى أين وصل.
- إعادة التوليد كاملة: `sh data-src/regen.sh`

## أسطورة بلده (`data-src/legends.txt`)
44 دولة بلا تاريخ كروي كبير وأساطيرها، مع سبب كونهم أساطير. لاعبون جدد للأساطير في `players12.txt`.

## البطاقة التعريفية للاعبين (`data-src/bios*.txt`)
لكل أسطورة: المركز المعروف به، اللقب، السمات المميزة، أفضل موسم، إحصائية مميزة، حكايات مع أنديته، أرقام القميص في كل نادٍ والمنتخب، الجوائز الفردية والألقاب الجماعية.
الصيغة موضحة أعلى `bios1.txt`. `build.py` يرفض: لاعبًا غير موجود، ناديًا لم يلعب له اللاعب، سمة غير معروفة، أو نصًا يكشف اسم اللاعب (لأن النصوص تُستخدم أدلة في الألعاب).
في الألعاب: السمات وأفضل موسم والحكايات أدلة إضافية لا تُستخدم وحدها لإثبات تفرد الإجابة؛ واللقب يظهر دائمًا آخر دليل.

## لاعبو كأس العالم (2,700 لاعب)
المصدر: [The Fjelstul World Cup Database](https://github.com/jfjelstul/worldcup) — CC-BY-SA 4.0 (الملفات في `data-src/wc/`).
| الملف | الدور |
|---|---|
| `wc_select.py` | يختار اللاعبين حسب حصة كل فترة (1998+: 1500، 1990–1998: 700، 1960–1990: 500)، ويُفضّل استكمال قوائم منتخبات كاملة؛ ويطابق اللاعبين الموجودين أصلًا بالاسم وتاريخ الميلاد |
| `wc/names_ar.txt` | الأسماء العربية (مُدخلة يدويًا) |
| `wc_import.py` | يولّد `wc/import.json`: اللاعبين، 208 قائمة منتخب كاملة بتشكيلة آخر مباراة، وقوائم كأس العالم لروابط الزمالة |

لإعادة التوليد: `python3 data-src/wc_select.py && python3 data-src/wc_import.py && python3 data-src/build.py`

## قواعد التوثيق المطبقة
- رابط زمالة عبر نادٍ يتطلب تداخل فترتي اللاعبين في الفريق الأول موسمًا كاملًا على الأقل.
- روابط المنتخبات تُستخرج من التشكيلات الموثقة فقط.
- شارة "موثقة" = روجعت مقابل سجل المباراة المنشور؛ "معرفة تاريخية" = بانتظار مراجعة مصدر ثانٍ.
- الصور: من ويكيبيديا/كومنز بعد التحقق أن الصفحة للاعب كرة قدم وأن الترخيص ليس "غير حر"، مع حفظ الترخيص والمصوّر وعرضهما.

## مسيرات الأندية للاعبي كأس العالم (1,284 لاعبًا)
المصدر: [ewenme/transfers](https://github.com/ewenme/transfers) — سجلات انتقالات Transfermarkt لتسعة دوريات (إنجلترا ودرجتها الثانية، إسبانيا، إيطاليا، ألمانيا، فرنسا، هولندا، البرتغال، روسيا) من موسم 1992/93 حتى 2022/23.
- يُطابق اللاعب بالاسم وسنة الميلاد معًا، ويُرفض أي تطابق غامض أو سلسلة انتقالات متناقضة (والأسماء المفردة مثل "فرناندينيو" تتطلب سلسلة متسقة تمامًا).
- تُحفظ الفترة فقط إذا عُرفت بدايتها ونهايتها، أو كان اللاعب ما زال في نادٍ مغطّى عند نهاية البيانات (يظهر "منذ …").
- فرق الشباب والرديف ليست فترات فريق أول. فترات الأندية خارج الدوريات التسعة لا تظهر.
- `tm/clubs_ar.txt`: الأسماء العربية للأندية الجديدة وربط الأسماء بأكواد الأندية الموجودة.

لإعادة التوليد: `python3 data-src/tm_careers.py && python3 data-src/tm_apply.py && python3 data-src/build.py`
