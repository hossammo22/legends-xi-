# LEGENDS XI — Football Time Machine
**Created by Dr HOSSAM Mo**

تطبيق Android: موسوعة تاريخية لكرة القدم + ألعاب معرفة.

## الحصول على ملف APK (بدون تثبيت أي برامج)
1. أنشئ مستودعًا جديدًا على GitHub (يمكن أن يكون خاصًا Private).
2. ارفع كل محتويات هذا المجلد إليه (زر **Add file → Upload files**، واسحب الملفات والمجلدات).
3. افتح تبويب **Actions** — سيبدأ البناء تلقائيًا (حوالي 8–12 دقيقة).
4. عند انتهائه ستجد ملف **LEGENDS-XI.apk** في:
   - صفحة **Releases** في المستودع، أو
   - صفحة تشغيل الـ Action تحت **Artifacts**.
5. حمّل الملف على هاتفك وافتحه، واسمح بالتثبيت من مصادر غير معروفة عند الطلب.

كل رفع جديد على الفرع `main` يبني نسخة جديدة تُثبَّت فوق السابقة مباشرة (توقيع ثابت للمشروع).

### للنشر على Google Play لاحقًا (اختياري)
أنشئ مفتاح توقيع خاص بك، ثم أضف في **Settings → Secrets → Actions**:
`LXI_KEYSTORE_BASE64` (الملف بصيغة base64)، `LXI_KEYSTORE_PASSWORD`، `LXI_KEY_ALIAS`، `LXI_KEY_PASSWORD`.
عندها سيبني الـ Action نسخة Release موقّعة بمفتاحك تلقائيًا.

## هيكل المشروع
| المسار | المحتوى |
|---|---|
| `data-src/` | قاعدة البيانات كنصوص قابلة للتعديل: `teams.txt`، `players*.txt`، `squads.txt` |
| `data-src/build.py` | يتحقق من البيانات ويولّد `www/js/data.js` (يرفض أي خطأ: لاعب ناقص، كود نادي مجهول، تشكيلة ليست 11…) |
| `www/` | التطبيق نفسه (HTML/CSS/JS) |
| `android/` | مشروع Android الأصلي (Capacitor) |
| `.github/workflows/build-apk.yml` | البناء التلقائي على GitHub |

## إضافة بيانات
- **لاعب**: سطر في أي ملف `players*.txt`:
  `id|English|عربي|N-XXX|POS|YYYY-MM-DD|tier|NTfrom-NTto|CLUB 1996-2001; CLUB2 2001-2005|WC2002 CL2005|aliases`
  السنوات = سنة بداية الموسم الأول – سنة نهاية الموسم الأخير.
- **تشكيلة**: كتلة جديدة في `squads.txt` (الصيغة موضحة أعلى الملف). الرقم غير المعروف يُكتب `-` ليظهر "غير موثق".
- ثم شغّل: `python3 data-src/build.py`

## قواعد التوثيق المطبقة
- رابط زمالة عبر نادٍ يتطلب تداخل فترتي اللاعبين في الفريق الأول موسمًا كاملًا على الأقل.
- روابط المنتخبات تُستخرج من التشكيلات الموثقة فقط.
- شارة "موثقة" = روجعت مقابل سجل المباراة المنشور؛ "معرفة تاريخية" = بانتظار مراجعة مصدر ثانٍ.
- الصور: من ويكيبيديا/كومنز بعد التحقق أن الصفحة للاعب كرة قدم وأن الترخيص ليس "غير حر"، مع حفظ الترخيص والمصوّر وعرضهما.
